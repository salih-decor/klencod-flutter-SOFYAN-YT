# الواجهة الأصلية (React + Vite) — للمرجع فقط

هذه نسخة من واجهة MVP الأصلية، محفوظة كما هي لتبقى الهوية والسلوك مرجعًا للتحويل.
**لا تعمل مع الخادم الجديد**: صار كل مسار `/api/*` (عدا `/api/health` والدخول) يتطلب رمز تسجيل دخول.
التطبيق المعتمد الآن هو Flutter في المجلد الرئيسي. يمكن حذف هذا المجلد بأمان.
