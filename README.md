# SOFYAN YT — Flutter Android

هذه نسخة Flutter أصلية لواجهة SOFYAN YT، مع الاحتفاظ بخادم FastAPI الأصلي في `backend/`.

## المنفذ فعليًا
- واجهة RTL ووضع ليلي/نهاري، رفع صور بالكاميرا أو الملفات، إرسال OCR إلى FastAPI، تعديل النص، اختيار المادة والشعبة، توليد الإجابات، التحقق، عرض السجل وحذف العناصر من الخادم، وتصدير PDF محليًا.
- صفحة الفلسفة تختار المنهجية ثم تنقلها إلى محلل الأسئلة؛ المساعد يستخدم طلبات الحل وليس محادثة متعددة الرسائل.
- مكتبة البكالوريا واجهة توضيحية فقط؛ لا توجد مصادر معتمدة أو RAG في هذه النسخة.

## غير منفذ
- الحسابات وتوثيق المستخدمين، قاعدة بيانات متعددة المستخدمين، RAG، مكتبة فعلية، تقييم جودة الإجابات، جلسات محادثة كاملة، تصحيح PDF على الخادم، والتعامل مع صور متعددة الصفحات داخل PDF يحتاج تطويرًا إضافيًا.
- خادم OCR الأصلي يدعم الصور فقط؛ ملفات PDF ستُرفض برسالة واضحة. واجهة رفع الملفات تسمح باختيارها ولكن هذا ليس دعمًا كاملاً لها.

## متطلبات تشغيل الخادم
راجع `backend/requirements.txt`، ثبت Tesseract مع حزم اللغات ara, fra, eng، ثم ضع مفتاح Anthropic في `backend/.env` وشغّل `uvicorn main:app --host 0.0.0.0 --port 8000` من مجلد backend. يجب نشر الخادم على HTTPS. قاعدة SQLite الأصلية مشتركة بين جميع الطلبات ولا تتضمن عزلًا للمستخدمين، فلا تنشرها للعامة دون إضافة المصادقة والتحكم بالوصول وتحديد معدل الطلبات.

## البناء
1. افتح مشروع Flutter من المجلد الذي يحتوي على `pubspec.yaml`.
2. `flutter pub get`
3. `flutter analyze`
4. `flutter build apk --release --dart-define=API_URL=https://your-secure-backend.example`
5. إذا كان KlencodIDE يحتاج ملفات Android مولدة من إصدار Flutter مطابق، يمكن تشغيل `flutter create --platforms=android .` داخل المجلد قبل البناء، ثم مراجعة إعدادات Android الناتجة.
6. GitHub Actions يتوقع أن يكون `pubspec.yaml` في جذر المستودع، واضبط Repository Variable باسم `SOFYAN_API_URL` بعنوان خادم HTTPS.

## تنبيهات
- هذه نسخة مصدرية غير مبنية؛ بيئة إعداد المشروع الحالية لا تحتوي Flutter أو Dart، ولم يتم تشغيل `flutter pub get` أو `flutter analyze` أو `flutter build apk`.
- إعداد release الحالي يستخدم مفتاح توقيع debug للتجربة فقط، وليس مناسبًا لنشر Google Play.
- مفاتيح Anthropic تبقى على الخادم؛ لا تضعها داخل APK أو GitHub.
